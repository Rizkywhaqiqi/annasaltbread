# Official Ana brand artwork

Source: owner-supplied `Brand Guidelines - Ana Saltbread.pdf`, Logo System page 9 (received 20 November 2026).

- `ana-wordmark.svg`: native black wordmark image object 456 and its original alpha mask.
- `ana-wordmark-white.svg`: native white wordmark image object 451 and its original alpha mask.
- `ana-flower.svg`: native black flower image object 73 and its original alpha mask.

The original decoded image data is embedded intact in SVG; viewboxes provide transparent clear space. No tracing, generative redrawing, recolouring or stretching is used. Existing bread cutouts remain derived from owner photography and menu sheets.
