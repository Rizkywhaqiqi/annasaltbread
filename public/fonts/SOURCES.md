# Ana website fonts

- Public Sans: existing self-hosted variable font, licensed under the accompanying SIL Open Font License.
- Arial Regular: browser/system font for body text and functional information.
- Vavinx-BrandSubset.ttf: merged original embedded Vavinx subsets from owner-supplied Brand Guidelines - Ana Saltbread.pdf (font objects 502, 409, 387; embedding permissions fsType=0). Only available Unicode characters are declared in the web font face. Used for short lowercase brand phrases; unsupported characters use Arial. This subset is not a complete Vavinx distribution.
